# Link-Transformer-Termux
Link Transformer — консольная утилита для Android (Termux), которая берёт обычную ссылку и превращает её в другую форму: короткую, «красивую» ЧПУ, с UTM-метками, в QR-код или в превью-карточку для мессенджеров.  Интерфейс — большое цветное меню.
Что умеет:

Пункт Действие Результат
1 Сократить Короткая ссылка через clck.ru
2 ЧПУ Ссылка вида site.ru/a3f9k2 (заготовка под свой домен)
3 UTM Ссылка + utm_source/medium/campaign
4 QR QR-код, нарисованный прямо в терминале
5 Превью HTML с OG-тегами для красивой карточки в Telegram/VK
0 Выход —

Стек: Python 3, colorama, requests, qrcode. Всё работает офлайн, кроме пункта 1 (нужен интернет).

---

Инструкция по запуску

Шаг 1. Установить Termux

Скачайте Termux из F-Droid (версия из Google Play устарела и не обновляется): https://f-droid.org/packages/com.termux/

Шаг 2. Обновить пакеты

```bash
pkg update && pkg upgrade -y
```

Шаг 3. Установить Python

```bash
pkg install python -y
```

Шаг 4. Установить зависимости

```bash
pip install colorama requests qrcode
```

Шаг 5. Создать файл скрипта

```bash
nano linkmenu.py
```

Вставьте код из предыдущего сообщения, сохраните: Ctrl+O → Enter, выйдите: Ctrl+X.

(Альтернатива: скопируйте код в файл на компьютере и перекиньте в Termux через termux-setup-storage и папку /sdcard/Download.)

Шаг 6. Запустить

```bash
python linkmenu.py
```

Шаг 7. Пользоваться

1. Появится переливающееся меню.
2. Введите цифру пункта (1–5) и нажмите Enter.
3. Вставьте ссылку (долгое нажатие → Paste) и Enter.
4. Получите результат. Enter — назад в меню, 0 — выход.

---

Возможные проблемы

Проблема Решение
pip: command not found pkg install python-pip -y
Пункт 1 выдаёт ошибку сети Проверьте интернет; clck.ru иногда блокирует запросы без User-Agent
QR не рисуется pip install qrcode[pil] или проверьте, что пункт 4 выбран
Цвета не отображаются Termux поддерживает truecolor по умолчанию; обновите Termux
Меню «дёргается» Уменьшите time.sleep в цикле или запустите в полноэкранном режиме

Идеи для развития

· Копирование результата в буфер: termux-clipboard-set "<ссылка>"
· Сокращение через Bitly с личным токеном
· Сохранение истории ссылок в links.txt
· Свой домен для ЧПУ-ссылок
· Генерация QR-картинки в файл (qrcode.make(url).save("qr.png"))
